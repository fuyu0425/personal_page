Embrace Open Model and Open Harness

I start with Claude Code, then Codex, and finally land on open harness.

Claude Code

Claude Code is so buggy and randomly freezes; Anthropic keeps randomly changing features; for example, the effort stuff, and the dark stuff around input cache and HTTP headers.

Codex

Codex was good before, like until July; but after catching up with Claude Code, they just show their true face! They keep nerfing the limits and use resets to disguise. They don’t honor the previously mentioned banked resets, and deliberately align the reset timing to the next natural reset as advertisement and karma farming (for example, close to the last reset + 7 days or the expiration of banked resets). Just such a disgusting and shady business practice.

The Deal Breaker: Auto Resolve

The final deal breaker for me is the newly added feature called auto resolve. There are already a lot of complaints after the feature was introduced, such as https://github.com/openai/codex/issues/28969. It will automatically proceed with the first choice when users are prompted with questions, like in 60 seconds. When in plan mode or brainstorming, that autoresolve is just disruptive. To make it worse, the project will drift a lot when you are asked questions but you are not babysitting Codex. I think that’s what OpenAI wants to achieve: let your projects become garbage and spend more tokens on guiding it back. All in all, DISGUSTING.

Pivot to Oh-My-Pi

Therefore, I pivot to oh-my-pi, the battery-included pi. I really want to hack pi from scratch like I hacked my Emacs configuration (10k+ LoC Emacs Lisp). But I am not a TypeScript guy and don’t have much capacity in life. So I decide to start with oh-my-pi to learn the ecosystem and, in one day, do my own fork with pi, if at that time the harness itself is still relevant.

Coding Plan

For a coding plan, I tried OpenCode Go ($10/mo, and $5 in the first month) with DeepSeek V4 Flash and Pro. All in all, it can do a good job in the domain I am familiar with and doesn’t cost too many tokens.

Conclusion

I know I will eventually settle on open harness as I did with Emacs, but the date is sooner than I originally thought. The world is changing so fast. Next plan is to get GPUs for local models so I don’t even need to subscribe to any coding plans.
